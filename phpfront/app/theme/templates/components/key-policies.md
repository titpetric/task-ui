# key-policies

Input scope: `data_whofield`, from `Task\WhoField::data()`, the same scope
[who-field](who-field.md) reads: this is the field around it on a key form —
the label, the element and the line under it.

The roles' boxes are named `policies` and the users' `users`, which is what
`/api/keys` takes; with nothing checked no run gets the key, so `empty` is "".
