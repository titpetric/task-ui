# Recents

The rail on the right of a wide screen: the latest runs, by anyone, newest
at the top, the way a chat app lists conversations. A screen narrower than
1200 pixels, a phone included, leaves the rail out; **Runs** in the
sidebar lists the same runs, and the rail's heading links there.

The rail lists the latest 50, under headings of when they started: **In
the last hour**, **1 hour ago**, **2 hours ago**, and past a day, **1 day
ago** and on. It ends where the page or the screen ends, whichever
comes first. When some entries don't fit, its last slot is **All runs**
with how many more there are, a link to **Runs**; when every entry fits,
the list ends with the last one.

Each entry shows how the run went (its dot), the job and folder, and who
started it, as their initials. A workflow run shows the workflow's name
and marks itself as a workflow. A run in progress carries a play or an
eye:

- **play** when you may run the job: attach on its page to type into it
  and end it;
- **eye** when you may only watch.

An entry links to its run's page, `/runs/<id>`, where **Attach** or
**View** opens the run window (see [Runs](runs.md)). A workflow run
links to its workflow's page.

Recents follow the runs as they start and end, with no reload.
