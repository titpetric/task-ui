# Sitemap

Every page of task-ui, by area: what it lists, the actions at the top right of its head, the actions of a row, its forms and what an empty list shows. [Development](development.md#lists-and-actions) has the conventions the pages follow. A row action in `[...]` is an item of the row's **⋯** menu; "Delete" and "Remove" are in red, last.

## Shared parts

| Part           | Template                 | Where                                                                                       |
|----------------|--------------------------|---------------------------------------------------------------------------------------------|
| Keys table     | `keyhead`, `keyrow`      | Keys, Instance, a workspace's page and its SSH keys page, Your SSH keys, a user's edit page |
| Secret fields  | `secretfields`           | Add variable and Edit                                                                       |
| Files table    | `tree`, `filetable`      | a folder's Files and a workspace's Home, a directory's page                                 |
| Projects table | `projecttable`           | each block of Projects, a workspace's page                                                  |
| Block head     | `blockhead`, from `head` | a block's title, its note, its buttons and the line of an empty list                        |
| Buttons        | `buttons`                | the buttons of a block head                                                                 |
| Copy           | `copyable`               | a public key, an ssh login, the MCP links and command, a token shown once                   |
| Row menu       | `menu`                   | every row and page head with actions besides its main one                                   |
